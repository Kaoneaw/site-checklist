# ไซต์เช็ค — โครงการฮิดายา

เว็บแอปติดตามงานก่อสร้างภาษาไทยในไฟล์ `index.html` ไฟล์เดียว เปิดด้วยเบราว์เซอร์รุ่นปัจจุบันได้ทันที ไม่ต้องติดตั้งหรือ build รองรับมือถือและ dark mode

## ข้อมูลโครงการ

อ้างอิง `R3 Master Plan HDY TH.xlsx`: โครงการฮิดายา อินฟราสตรักชั่น แอนด์ วิลล่า เกาะพะงัน

- ระยะ 1.1: B8, A9, A5, A6, B7, C11
- ระยะ 1.2: B1, B2, B3, B4, B13, C12
- งานโครงสร้างพื้นฐานเป็นพื้นที่ส่วนกลางแยกจากจำนวนวิลล่า
- 185 งานหลัก และ 632 รายละเอียดงานย่อย รวมงานเพิ่ม 48 งานหลัก
- แผนปฏิทิน 14 กันยายน 2026 ถึง 3 มกราคม 2027 ไม่ใช่หลักฐานการเริ่ม/เสร็จจริง

เปิดครั้งแรกในเบราว์เซอร์ใหม่จะใช้ข้อมูลจาก Excel อัตโนมัติ หากมีข้อมูลเก่า ระบบจะรักษาไว้ ให้กด **ใช้ข้อมูลโครงการจาก Excel** เพื่อเปลี่ยนแผนหลังยืนยัน ระบบจะเก็บสำรองก่อนเปลี่ยนทั้งใน localStorage และดาวน์โหลด JSON สามารถใช้ปุ่ม **กู้คืนข้อมูลก่อนโหลดแผน** เพื่อย้อนกลับได้ สำรองในเครื่องนี้เก็บข้อมูลก่อนเปลี่ยนแผนครั้งล่าสุดเท่านั้น

## การใช้งาน

- ดูสถานะผ่านแดชบอร์ด เช็คลิสต์รายหลัง หรือตาราง Matrix
- กดรายละเอียดงานย่อยเพื่อเปิดเช็คลิสต์ย่อย การติ๊กงานย่อยจะคำนวณสถานะงานหลักใหม่ เมื่อทุกงานย่อยเสร็จ งานหลักจะเสร็จพร้อมวันที่ปัจจุบัน
- เปลี่ยนสถานะงานหลักเป็นเสร็จจะติ๊กงานย่อยทั้งหมด เปลี่ยนกลับเป็นยังไม่ได้ทำจะล้างสถานะงานย่อย งานย่อยไม่ถูกนับซ้ำในสถิติหลัก
- สถานะต้นทางและเปอร์เซ็นต์ Excel คงเดิมเพื่ออ้างอิง แยกจากสถานะที่ผู้ใช้ปรับปัจจุบัน
- แก้ชื่องาน/หลัง ผู้รับผิดชอบ วันที่ หมายเหตุ และข้อมูล Extra ได้ เพิ่มงานเดียวกันพร้อมกันหลายหลังได้ มูลค่าที่กรอกเป็นมูลค่าต่อหลัง
- กรองตามระยะ หลัง หมวด สถานะ ประเภท ผู้รับผิดชอบ และค้นหาชื่องานหลัก ตัวกรองใช้กับรายการ การ์ด Matrix สรุป Extra และ CSV สถิติด้านบนแสดงทั้งโครงการเสมอ
- เทมเพลต 27 แบบมาจากขอบเขตงานมาตรฐานของแต่ละหลัง เลือกทั้งงานและหลังที่จะนำไปใช้ได้ ควรเลือกขอบเขตให้เหมาะกับระยะและหลัง ไม่เพิ่มงานชื่อ/หมวดซ้ำ
- CSV มีข้อมูลต้นทางและรายละเอียดงานย่อย พิมพ์/PDF ตามมุมมองปัจจุบัน โดยขยายรายละเอียดงานย่อยอัตโนมัติขณะพิมพ์
- สำรองและกู้คืน JSON ได้ การกู้คืนจะแทนที่ข้อมูลทั้งหมดหลังยืนยัน

## การอ่านข้อมูลที่ไม่ครบ

ความคืบหน้ารวม = จำนวนงานหลักที่เสร็จ / จำนวนงานหลักทั้งหมด (รวม Extra) ไม่ใช่ค่าเฉลี่ยเปอร์เซ็นต์ในแผน ไม่ใช่ความคืบหน้าตามมูลค่าหรือปริมาณงาน

Excel มีงานหลักเสร็จ 4 งาน กำลังทำ 11 งาน ยังเหลือ/0% 138 งาน และไม่ระบุสถานะ 32 งาน ช่องว่างขึ้น **รอยืนยันสถานะ** และรวมในกลุ่มงานยังไม่เสร็จ ไม่อนุมานความคืบหน้าจากสี Gantt หรือวันที่แผนที่ผ่านไป

ไฟล์ไม่มีมูลค่า Extra ผู้ขอ/วันที่ขอ ผู้รับผิดชอบ และวันเสร็จจริง จึงไม่สร้างค่าขึ้นเอง มูลค่าไม่ทราบแสดง **ยังไม่ระบุมูลค่า** ไม่ใช่มูลค่าศูนย์ และถูกแยกจำนวนออกจากยอดที่ระบุแล้ว

ดูรายละเอียดแหล่งอ้างอิงและการตรวจสอบได้ใน [docs/EXCEL_MAPPING.md](docs/EXCEL_MAPPING.md)

## ข้อมูลและความเป็นส่วนตัว

ข้อมูลบันทึกใน localStorage ของแต่ละเบราว์เซอร์/อุปกรณ์ ไม่ซิงก์ข้ามเครื่อง ให้ย้ายข้อมูลด้วย Backup/Restore JSON ใช้ URL หรือไฟล์ตำแหน่งเดิมและสำรองเป็นประจำ หลีกเลี่ยงแก้ไขหลายแท็บพร้อมกัน โหมดส่วนตัว การล้างข้อมูลเบราว์เซอร์ หรือย้ายไฟล์อาจทำให้เข้าถึงข้อมูลเดิมไม่ได้

แอปทำงานออฟไลน์ได้ ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts เมื่อออนไลน์และใช้ฟอนต์ไทยในเครื่องเมื่อออฟไลน์ ไม่มี API หรือฐานข้อมูลภายนอก ข้อมูลแผนตั้งต้นฝังอยู่ใน HTML ผู้ที่เข้าถึงเว็บไซต์/โค้ดจึงอ่านแผนตั้งต้นได้ ส่วนการแก้ไขในเบราว์เซอร์จะไม่ส่งกลับ GitHub ไฟล์ Excel ต้นฉบับไม่ได้รวมใน repository

## GitHub Pages

`.github/workflows/pages.yml` เผยแพร่เฉพาะ `index.html`

1. Repository ต้องรองรับ Pages (Public บนแผนฟรี หรือแผนที่รองรับ Private)
2. ใน **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. เมื่อ push `index.html` เข้า `main` จะรันเผยแพร่อัตโนมัติ หรือเปิด **Actions → Publish checklist website → Run workflow**
4. ใช้ลิงก์ที่ GitHub แสดงหลัง deployment สำเร็จ เปิดได้ทั้งคอมพิวเตอร์และมือถือ

การ push โค้ดไม่ยืนยันว่าการเผยแพร่สำเร็จ ต้องตรวจผล Actions ด้วย

## ตรวจความตรงกับ Excel (สำหรับผู้พัฒนาเท่านั้น)

ใช้ Python ที่มี openpyxl อยู่แล้ว:

```sh
python3 tests/verify_excel.py '/path/to/R3 Master Plan HDY TH.xlsx'
```

ตรวจทุกแถวงาน 817 แถวว่าถูกนำเข้าครั้งเดียว ชื่องาน สถานะ ช่องว่าง งานเพิ่ม และวันที่แผนตรงต้นฉบับ ไม่จำเป็นต้องรันหรือติดตั้งเครื่องมือเหล่านี้เพื่อเปิดใช้เว็บ
