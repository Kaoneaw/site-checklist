# ไซต์เช็ค — เช็คลิสต์งานก่อสร้างหลายยูนิต

เปิด `index.html` ในเบราว์เซอร์รุ่นปัจจุบันได้ทันที ไม่ต้องติดตั้งหรือสั่ง build

- มีข้อมูลตัวอย่าง 4 หลัง พร้อมเทมเพลต 8 หมวด กดล้างข้อมูลตัวอย่างเพื่อเริ่มโครงการจริง
- เพิ่มหลัง ใช้เทมเพลตกับทุกหลังหรือเลือกบางหลัง แล้วติดตามงานผ่านเช็คลิสต์และตาราง Matrix
- เพิ่มงานสัญญาหรืองานเพิ่มพร้อมกันหลายหลังได้ มูลค่างานเพิ่มที่กรอกเป็นมูลค่าต่อหลัง
- ตัวกรองใช้กับรายการงาน การ์ดรายหลัง Matrix สรุปงานเพิ่ม และ CSV ส่วนสถิติด้านบนแสดงทั้งโครงการเสมอ
- กดสถานะใน Matrix เพื่อวน ยังไม่ได้ทำ → กำลังทำ → เสร็จแล้ว
- ติ๊กเสร็จจะใส่วันที่ปัจจุบัน แก้วันที่เสร็จจริงได้ในฟอร์มงาน
- พิมพ์รายงานจากมุมมองปัจจุบัน แล้วเลือก “บันทึกเป็น PDF” ในหน้าต่างพิมพ์
- สำรอง JSON เป็นประจำ การกู้คืนจะแทนที่ข้อมูลทั้งหมดหลังยืนยัน

ข้อมูลบันทึกใน localStorage ของเบราว์เซอร์และอุปกรณ์นั้น ไม่ซิงก์ข้ามเครื่อง การย้าย/เปลี่ยนชื่อไฟล์หรือใช้โหมดส่วนตัวอาจทำให้เข้าถึงข้อมูลเดิมไม่ได้ ควรสำรอง JSON ก่อนย้ายไฟล์ หลีกเลี่ยงแก้ไขหลายแท็บพร้อมกัน

ตัวแอปทำงานแบบออฟไลน์ได้ ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts เมื่อออนไลน์ หากออฟไลน์จะใช้ฟอนต์ไทยที่มีในเครื่อง ไม่มีบริการภายนอกหรือ API ที่ต้องตั้งค่าสำหรับข้อมูลโครงการ

## เปิดผ่านลิงก์เว็บบนคอมพิวเตอร์และมือถือ

เตรียม workflow ไว้ใน `.github/workflows/pages.yml` ซึ่งเผยแพร่เฉพาะ `index.html` โดยไม่ส่งไฟล์อื่นใน repository ขึ้นเว็บไซต์

1. นำไฟล์แอปและ workflow ขึ้น repository บน GitHub
2. ใน repository เปิด **Settings → Pages → Build and deployment → Source: GitHub Actions** (ต้องมีสิทธิ์จัดการ repository และแผน GitHub ที่รองรับ Pages สำหรับ repository นี้)
3. เปิด **Actions → Publish checklist website → Run workflow** หรือใช้การ push เข้า `main`
4. ใช้ลิงก์ที่ GitHub แสดงหลัง deployment สำเร็จ เปิดได้ทั้งคอมพิวเตอร์และมือถือ

เว็บไซต์ที่เผยแพร่อาจเปิดให้บุคคลทั่วไปเข้าถึงได้ ขึ้นอยู่กับการตั้งค่าและแผน GitHub ตัวแอปเก็บข้อมูลโครงการไว้ในเบราว์เซอร์ของแต่ละอุปกรณ์ ไม่ส่งขึ้น GitHub และไม่ซิงก์อัตโนมัติ ย้ายข้อมูลระหว่างเครื่องด้วย Backup/Restore JSON การใช้ HTTPS ช่วยให้ localStorage มีที่อยู่เว็บไซต์คงที่ แต่ยังควรสำรองข้อมูลเป็นประจำ

การเตรียม workflow ยังไม่ใช่การเผยแพร่จริง ต้องเปิด Pages และรัน deployment สำเร็จก่อนจึงมีลิงก์ใช้งาน
